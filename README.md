# Proyecto Urban.Routes 

Este proyecto contiene la automatización de 9 pruebas que evaluan la funcionalidad 
del proceso completo de pedir un taxi en Urban.Routes.

-Los localizadores y métodos están en la clase UrbanRoutesPage ubicada en el archivo urban_routes_pages.py

-Las pruebas están en la clase TestUrbanRoutes ubicada en el archivo test_urban_routes.py

-Necesitas tener instalado pytest y selenium para ejecutar las pruebas.

-Ejecuta todas las pruebas con el comando pytest
